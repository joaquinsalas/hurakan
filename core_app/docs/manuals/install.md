## About <a name = "about"></a>
Hurakán is a multiservice, web-based platform that forecasts tropical cyclone (TC) trajectories. It integrates atmospheric scenarios generated by probabilistic, data-driven forecasting systems. Although global in scope, it has been implemented with regions of interest (ROIs) focused on the Mexican coastlines.

The platform requires a web server and a web client. The server downloads and processes atmospheric data, displays daily forecasts as interactive maps, and classifies the analyzed data to improve the identification of potential tropical cyclones.



## Getting Started <a name = "getting_started"></a>
These instructions will help you set up and run a local copy of the project for development and testing.

Python and other software dependencies are required. For simplicity, we recommend using a Docker container, which allows the application to run on Windows, macOS, or GNU/Linux.

You need one computer to act as the web server, where the project runs, and another computer to act as the client, where users interact with the web interface through a browser. Docker is not required on the client computer.


### Prerequisites
Hurakán relies on several Python 3.11+ libraries and Docker. During installation, the required libraries are downloaded from open-source software repositories.

Docker Engine is open-source software, whereas Docker Desktop is proprietary and may require a paid subscription. For installation instructions on Windows, macOS, or GNU/Linux, see [Docker Desktop](https://docs.docker.com/desktop/#next-steps).

Hurakán also requires atmospheric data for a specific date, such as the current day.


### Installation

### 1. Clone the repository

``````````````````````````````````````````````````````````````````````````````````
git clone https://github.com/joaquinsalas/hurakan
cd hurakan
```````````````````````````````````````````````````````````````````````````````````


```bash

cd hurakan
```

### 2. Create a virtual environment

The required libraries will be installed only inside the virtual environment.

```bash
python3 -m venv .venv
```

> [!NOTE]
> `python3` must execute Python 3.11 or later on the host system.

### 3. Activate the virtual environment

**Windows:**

```powershell
.venv\Scripts\activate
```

**macOS or GNU/Linux:**

```bash
source .venv/bin/activate
```

After activation, the command prompt will include the virtual environment name in parentheses:

```text
(.venv) hurakan$
```

### 4. Copy the required environment-variable file

**Windows:**

```powershell
(.venv) hurakan$ copy .env.example .env
```

**macOS or GNU/Linux:**

```bash
(.venv) hurakan$ cp .env.example .env
```

> [!NOTE]
> You can either export the variables defined in the `.env` file or install `python-dotenv` for the next step.

Install `python-dotenv`:

```bash
(.venv) hurakan$ pip install python-dotenv
```

### 5. Create the required directory structure

```bash
(.venv) hurakan$ python services/utils/init_folders.py
```

> [!NOTE]
> Inside the `.venv` virtual environment, `python` executes Python 3.11 or later.

### 6. Build the Docker images and start the services

```bash
(.venv) hurakan$ docker compose up --build
```

### 7. Install the requirements for `core_app`

```bash
(.venv) hurakan$ cd core_app
(.venv) hurakan/core_app$ pip install -r requirements.txt
```

### 8. Create authorized Hurakán users

```bash
(.venv) hurakan/core_app$ python create_users.py
```

### 9. Install the data-download requirements

```bash
(.venv) hurakan/core_app$ cd ..
(.venv) hurakan$ pip install -r librerias_download.txt
```

### 10. Generate Google Drive API credentials

> [!NOTE]
> Obtain both the token and credentials files in JSON format to access the Google Drive API.

### 11. Configure the required directories in the `.env` file

Open the `.env` file with a text editor:

```bash
(.venv) hurakan$ nano .env
```

> [!NOTE]
> Update the `TOKEN_FILE` and `CREDENTIALS_FILE` variables to provide access to the Google Drive API. Also update `DATA_RAW_DIR` to specify the directory where the atmospheric data will be downloaded.

### 12. Run the data downloader

Run it as a shell script:

```bash
(.venv) hurakan$ cd services/download_data
(.venv) hurakan/services/download_data$ ./run_download.sh
```

Alternatively, create a system service for the downloader on macOS or GNU/Linux:

```bash
sudo nano /etc/systemd/system/download_weather.service
```

Configure `download_weather.service` as follows:

```ini
[Unit]
Description=Continuous download of WeatherNext NetCDF data
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=<your_user>
ExecStart=/bin/bash -lc 'cd "/opt/hurakan/services/download_data" && "./run_download.sh"'
Restart=always
RestartSec=30
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Manage the downloader service with the following commands:

```bash
sudo systemctl enable download_weather.service
sudo systemctl start download_weather.service
sudo systemctl stop download_weather.service
sudo systemctl disable download_weather.service
```




## Usage <a name = "usage"></a>

To use the application from a client machine, open `http://<server-address>:8081` in a web browser.

If the browser is running on the server itself, use `http://127.0.0.1:8081`.

For detailed information, see the [User Manual](./usermanual.md).



## Deployment <a name = "deployment"></a>
As mentioned, you can build the Docker image on Windows, macOS, or GNU/Linux. However, the container should run on the same operating system and version used to build the image—for example, build it on Windows 11 and run it on Windows 11.

To run the Docker container:
```````````````````````````````````````````````````````````````````````````````````
docker compose up
```````````````````````````````````````````````````````````````````````````````````

To stop the running services and remove the containers, networks and images defined in the file:
```````````````````````````````````````````````````````````````````````````````````
docker compose down
```````````````````````````````````````````````````````````````````````````````````
